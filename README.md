# Portafolio web

Plantilla de portafolio personal desarrollada con diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías

HTML5, CSS3.

## Cómo empezar

Clona el repositorio y abre el archivo HTML principal en tu navegador o servidor estático.

Repositorio: https://github.com/jm181987/jmpage

## Mantenimiento y seguridad

- Comprueba los requisitos y scripts disponibles antes de desplegar.
- No publiques claves, tokens, contraseñas ni archivos de entorno.
- Documenta los cambios y los problemas reproducibles mediante issues o pull requests.
